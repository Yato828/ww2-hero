# Женское лицо Победы

Лендинг о Зинаиде Михайловне Туснолобовой-Марченко. React + TypeScript + Vite, обычный CSS без UI-фреймворка. Архивная фотография и шрифты размещены локально.

## Запуск

Нужен Node.js 22.18+.

```sh
npm ci
npm run dev
```

Vite выведет адрес локального сервера, по умолчанию `http://127.0.0.1:5173`.

## Сборка и проверки

```sh
npm run typecheck
npm run build
npm run preview
```

`build` сначала проверяет типы, затем создаёт оптимизированный сайт в `dist/`. Эту папку можно разместить на статическом хостинге. `preview` позволяет проверить собранный сайт локально; это не production-сервер. Версии зависимостей зафиксированы в `package-lock.json`.

## Структура

```text
public/
  images/               # Настоящий архивный портрет
  fonts/                # WOFF2 и лицензии SIL OFL
src/
  components/           # Header, Hero, Timeline, Letter, Memorial, Sources, Footer
  data/story.ts         # Тексты хронографии, цитата, ссылки на источники
  hooks/
    useReveal.ts        # Появление событий, reduced motion, cleanup
    useReadingProgress.ts
  styles/
    tokens.css          # Палитра, шрифты, ширина, отступы
    global.css          # Сброс, общие элементы, доступность
    header.css
    hero.css
    story.css           # Хронограф, письмо, источники
    memorial.css
    footer.css
  App.tsx               # Композиция страницы
  main.tsx              # Точка входа и подключение CSS
```

Для изменения текстов редактируйте `src/data/story.ts`, для изменения палитры — `src/styles/tokens.css`. Разметка секций и их интерактивное поведение находятся в отдельных компонентах. Шрифты Cormorant Garamond и Manrope не требуют запросов к Google; лицензии лежат рядом с файлами шрифтов.

## Интерактивность

- Закреплённая навигация, мобильное меню, индикатор прочтения и плавные якорные переходы.
- Хронограф с нативными `details` и появлением через Intersection Observer. При запрете анимаций или отсутствии API текст сразу доступен. Элементы также появляются при переходе по якорю или фокусе с клавиатуры.
- Постоянно горящая CSS-свеча с подписью «В память о героическом подвиге». Свеча видна сразу при открытии страницы; ей не нужны кнопка, счётчик или хранилище браузера.
- Клавиатурная навигация, видимый фокус, skip link и поддержка `prefers-reduced-motion`.

## Исторические материалы

Источники приведены на странице и в `src/data/story.ts`: городской архив Кемерова, администрация Ленинска-Кузнецкого и проект «Медсанбат» ЦНИИОИЗ Минздрава России. На фронт Зинаида ушла в 1942 году. В блоке письма приведён проверенный фрагмент; исходная ошибочная формулировка исправлена. Портрет 1941 года взят с Wikimedia Commons, автор неизвестен, статус общественного достояния указан в карточке изображения.
